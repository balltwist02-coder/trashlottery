# Автопроверки игры

Запускают игру в браузере без экрана и проходят основные сценарии. Нужны, чтобы правка в одном месте не ломала другое — особенно теперь, когда код разделён на части в `src/`.

## Как запустить

```sh
sh tests/setup.sh          # один раз: скачивает three.js r160 и cannon-es 0.20.0 в tests/.cache
node tests/smoke.cjs       # все сценарии (~2 минуты)
node tests/smoke.cjs bagSurface pile   # только выбранные
V=1 node tests/smoke.cjs   # подробно: каждая проверка
```

Нужны Node.js, пакет `playwright` и Google Chrome (`CHROME=/путь/к/chrome`, если не в `/usr/bin/google-chrome`). Скриншоты каждого сценария — в `tests/out/` (в git не попадают).

## Что проверяется

| Сценарий | Что ловит |
|---|---|
| load | игра загрузилась без ошибок, у всех вещей есть категория |
| dig | копание 3 слоёв, Кирью падает на дно и стоит |
| carryEdge | с вещью доходит до края вплотную, у края — над головой, положенная вещь лежит на полу |
| carryDepth | с вещью ходит по яме вдоль стенок и не застревает |
| noAutoRotate | длинная вещь (скелет) сама не перехватывается |
| pile | вещи не проходят друг сквозь друга, поставленная на кучу лежит сверху |
| bagSurface, bagDepth | мешок расстилается и сворачивается, камера не срезает землю (мерцание) |
| ladder | лестницу в руках можно донести до стенки и повесить |
| shop | с поддельным Телеграмом и сервером: письмо налоговой, арест круток, оплата налога снимает арест, удача списывается сервером при крутке |
| pickaxe | кирка 2×2 покупается и один удар копает квадрат |
| phone | телефон открывается и закрывается |

Кроме того, любая ошибка JavaScript в игре во время сценария — провал.

Перед сценариями тесты проверяют, что `3d_main.js` собран из свежего `src/` (`node tools/build.cjs --check`). Тесты опираются на `window.__dbg` (последняя часть, `src/18_save_map.js`). Проверено: на версии v48 тесты ловят найденные тогда ошибки (край карты, куча вещей, мерцание мешка, перехват скелета).
