# Код игры по частям

Браузер грузит один файл `3d_main.js`, но править нужно **здесь**: каждый файл — своя тема. После правки:

```sh
node tools/build.cjs        # собрать 3d_main.js и demo_main.js
node tests/smoke.cjs        # автопроверки (сначала сами проверяют, что сборка свежая)
```

Части склеиваются по порядку номеров в один модуль, поэтому всё, что объявлено в одной части, видно во всех следующих (как и раньше в одном файле). Новую часть называем `NN_тема.js` — номер задаёт место в сборке.

Ошибка в консоли браузера указывает строку `3d_main.js`; найти её в частях: `node tools/build.cjs --where 1234`.
